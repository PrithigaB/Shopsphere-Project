# ShopSphere - Django Ecommerce Website

ShopSphere is a full-stack ecommerce web application developed using Python and Django. The website provides an online shopping experience where users can browse products, search items, filter categories, and manage their shopping cart efficiently.

The project is designed with a clean user interface and dynamic functionalities to simulate a real-world ecommerce platform.

## Key Features

### Product Management
- Displays multiple products with images, descriptions, and prices
- Products are categorized for easy browsing
- Trending and offer products are highlighted separately

### Search & Filtering
- Search products using keywords
- Filter products based on categories
- View trending and discounted products instantly

### Cart Functionality
- Add products to cart
- Increase or decrease product quantity
- Automatically calculates total cart amount
- Dynamic cart count displayed in navigation bar

### User Authentication
- User login and logout system
- Protected cart access using authentication
- Personalized user profile page

### Responsive Navigation
- Navigation bar with search functionality
- Quick access to Home, Support, Know Us, Cart, and Profile pages
